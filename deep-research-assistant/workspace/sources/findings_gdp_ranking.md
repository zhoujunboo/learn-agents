# 2023 年全国 GDP 总量及各省 GDP 排名调研结果

## 一、2023 年全国 GDP 总量

根据**国家统计局**发布的《2023 年国民经济和社会发展统计公报》：

| 指标 | 数值 |
|------|------|
| 2023 年全年国内生产总值（GDP） | **1260582 亿元**（约 126.06 万亿元） |
| 比上年增长 | **5.2%** |
| 第一产业增加值 | 89755 亿元，增长 4.1% |
| 第二产业增加值 | 482589 亿元，增长 4.7% |
| 第三产业增加值 | 688238 亿元，增长 5.8% |

**数据来源**：国家统计局、界面新闻报道  
**来源 URL**：https://m.jiemian.com/article/10856816_toutiao.html

### 季度增长态势
2023 年四个季度 GDP 同比分别增长 4.5%、6.3%、4.9%、5.2%，呈现**前低、中高、后稳**态势。

## 三、关键发现

1. **全国经济稳步增长**：2023 年全国 GDP 达到 126.06 万亿元，实现 5.2% 的增长，完成了 5% 左右的预期目标。

2. **前三强格局稳定**：广东、江苏、山东三省继续稳居 GDP 排名前三位，三省 GDP 总量占全国 GDP 的三分之一左右。

3. **区域发展特点**：
   - 东部沿海地区仍是国内 GDP 的主要增长极
   - 西部地区（如四川）得到持续快速发展
   - 中部省份（河南、湖北、湖南、安徽）经济总量稳步提升

4. **增速表现**：2023 年经济增速比上年加快 2.2 个百分点，也快于疫情三年 4.5% 的平均增速。

## 四、数据说明

- 全国 GDP 数据来源于国家统计局官方发布的《2023 年国民经济和社会发展统计公报》
- 各省 GDP 数据来源于各省份统计局公布及权威媒体报道
- 部分省份具体数值因统计口径和发布时间差异可能存在细微差别，以各省份官方最终公布数据为准
